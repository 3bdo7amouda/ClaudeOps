## Funnel Stages
```
Awareness   → Content, SEO, social, PR
Interest    → Lead magnet, newsletter, retargeting
Desire      → Case studies, demos, trials
Action      → Checkout, signup, purchase
Retention   → Onboarding, email sequences, support
Referral    → Affiliate, word-of-mouth, review requests
```

## Ad Copy Formula (AIDA)
```
Attention: [Bold claim or question that stops the scroll]
Interest:  [Specific benefit or insight]
Desire:    [Social proof, outcome, or urgency]
Action:    [Single clear CTA]
```

## From: marketingskills (ad-creative)
Platform character limits:
```
Google Ads (RSA):
  Headline:    30 chars (up to 15 headlines)
  Description: 90 chars (up to 4 descriptions)
  Path:        15 chars each (2 paths)

Meta Ads:
  Primary text: 125 chars (preview) / 500 max
  Headline:     40 chars
  Description:  30 chars

LinkedIn Ads:
  Headline:     70 chars
  Description:  70 chars

Headlines must make sense independently and in any combination.
Pin only when mandatory — reduces Google's optimization.
```

## Email Sequence (SaaS trial)
```
Day 0:  Welcome — what to do first (one action)
Day 1:  Key feature intro — show fastest path to value
Day 3:  Social proof — customer story or stat
Day 5:  Address top objection
Day 7:  Trial ending reminder + offer
Day 10: Last chance + support offer
```

## From: marketingskills (churn-prevention)
Churn prevention quick wins:
```
Voluntary churn (50-70% of total):
  → Cancel flow with exit survey (learn why)
  → Save offer: pause > downgrade > discount (in that order)
  → Exit survey questions: "What's your main reason?" + "What would keep you?"

Involuntary churn (30-50%):
  → Smart retry schedule: day 1, 3, 7, 14 after failure
  → Dunning email sequence: friendly → urgent → final notice
  → Card updater service (Stripe Radar, Chargebee)

Proactive retention signals:
  → Login frequency drops > 50% → trigger re-engagement
  → Feature usage stops → send targeted tip
  → D7 activation incomplete → offer onboarding call
```
